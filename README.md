# IsotopeLab 0.2 — инструкция и математическая модель

Откройте `index.html` в браузере. Справочники хранятся в `localStorage`; экспортируйте JSON для резервного копирования и обмена между компьютерами. Данные не передаются на сервер. Кнопка «Формулы и JSON» содержит встроенную справку.

## Ввод потоков

Допустимы `1.6E14`, `1.6e14`, `2e12`, `0`, `160000000000000`. Запятая в качестве десятичного разделителя также принимается в этих полях. Размерность потоков — н/(см²·с). Числа в JSON пишутся как `1.6e14`, без кавычек. Групповые сечения — в барнах. Все значения должны быть неотрицательными.

## Циклы

Выберите «Циклы работы / остановки». Предустановлена последовательность: 100 ч работа, 40 ч остановка, 96 ч работа, 34 ч остановка. Этапы можно добавлять и удалять, выбирать тип, менять длительность, повторять всю последовательность от 1 до 100 раз. При остановке потоки всех групп становятся нулевыми, но распад и превращение промежуточного нуклида продолжаются. «Конец облучения (EOI)» — завершение последнего этапа программы, в том числе когда он является остановкой. «Выдержка» добавляется после программы. Для оценки активности непосредственно после последнего включённого этапа удалите завершающую остановку из программы или рассматривайте соответствующее значение графика.

## Формулы

Количество атомов исходного нуклида:

`N0 = (m × 10^-3 / M) × N_A × f / 100`, где `m` — масса элементного материала в мг, `M` — молярная масса в г/моль, `f` — обогащение в %.

Эффективная скорость реакции:

`k = 10^-24 × sum_g(phi_g × sigma_g)` в с^-1, где `phi_g` — интегральный поток энергетической группы, `sigma_g` — **спектрально-усреднённое** сечение группы в барнах. `kp` вычисляется точно так же по полям `productThermal`, `productEpi`, `productFast`.

Для прямой реакции (мишень `T` -> продукт `P`):

`dT/dt = -kT`

`dP/dt = kT - (lambda + kp)P`

Для двухстадийной реакции (мишень `T` -> предшественник `I` -> продукт `P`):

`dT/dt = -kT`

`dI/dt = kT - lambda_I I`

`dP/dt = lambda_I I - (lambda + kp)P`

Активность `A = lambda × P`, `lambda = ln(2) / T_half`. Система решается интегратором RK4, на каждой границе этапа состояние переносится на следующий. При остановке `k=kp=0`. При выдержке также нулевой поток. Активность к поставке равна активности после выдержки, умноженной на заданную долю выхода обработки.

Предположения: 0D, постоянный поток на включённых этапах; полное истощение мишенного изотопа определяется только реакцией образования; для продукта добавлено эффективное удаление через захват; не учитываются пространственная самозащита и выгорание предшественника, примеси, технологический распад во время химической переработки и изменение состава мишени. Параметр «удельная активность» делится на массу исходного элемента, поэтому не соответствует молярной активности готового радиофармпрепарата.

## JSON

Импорт/экспорт содержит корневые поля `format` (`"IsotopeLab"`), `version` (целое число), `channels` (массив каналов), `isotopes` (массив реакций).

**Канал:** `id` — уникальный строковый идентификатор, `name` — человекочитаемое название, `thermal`, `epi`, `fast` — потоки трёх групп, `note` — источник, примечание.

**Реакция:** `id`, `name`, `note`, `scheme` (`"direct"` либо `"chain"`), `targetMass` (г/моль), `productHalfDays` (сутки), `precursorHalfHours` (часы; требуется при `chain`), `thermal`, `epi`, `fast` (барн, образование), `productThermal`, `productEpi`, `productFast` (барн, удаление продукта).

Поле с нулём означает нулевой вклад в расчёт, а не отсутствие данных. Для неизвестного сечения не подставляйте нуль без оговорки. Пример в `example-library.json` демонстрационный и не описывает действующие каналы ИРТ-Т.

Для сохранения программ облучения необходима отдельная функция: текущий JSON экспортирует только библиотеки каналов и реакций, не параметры сценария.


## Общая библиотека с веб-сервера (версия 0.3)

1. Разместите `index.html` и `shared-library.json` в одной папке на HTTP(S)-сервере. При открытии страницы приложение автоматически запрашивает `./shared-library.json`.
2. При необходимости укажите в поле «Общая библиотека» другой путь, например `/data/isotopes.json` или `https://example.org/data/isotopes.json`, затем нажмите «Обновить». URL сохраняется в браузере.
3. Серверный файл — обычный JSON с массивами `channels` и `isotopes`. Формат совместим с `example-library.json`; пример для публикации — `shared-library.json`. Потоки и сечения допускают JSON-числа в экспоненциальной форме `1.6e14` (без кавычек).
4. Общие записи показываются вместе с личными и помечаются «🌐 Общая». Изменить их через сайт нельзя: доступна кнопка «В мои записи», создающая отдельную редактируемую копию в localStorage. При совпадающих `id` личная запись имеет приоритет; используйте уникальные префиксы ID.
5. Экспорт и импорт через интерфейс затрагивают **только личную библиотеку**, общий JSON они не перезаписывают. Изменить общий справочник может администратор, обновив JSON на сервере. После этого посетители увидят новую версию при следующем посещении/обновлении.
6. Если сервер библиотеки находится на другом домене, настройте CORS (`Access-Control-Allow-Origin`) на сервере JSON. При открытии HTML через `file://` сетевое чтение может блокироваться; используйте HTTP(S), например `python -m http.server 8000` и откройте `http://localhost:8000/`.
7. Не публикуйте реальные характеристики облучательных каналов и другую служебную информацию в общедоступном JSON без разрешения на раскрытие. Демо-значения реакций не являются аттестованными ядерными данными.

**Пример разметки JSON:**
```json
{
  "format": "IsotopeLab",
  "version": 3,
  "channels": [],
  "isotopes": [{
    "id": "example_direct",
    "name": "Демонстрационная реакция",
    "scheme": "direct",
    "targetMass": 175.9438,
    "productHalfDays": 6.647,
    "precursorHalfHours": 0,
    "thermal": 2090, "epi": 0, "fast": 0,
    "productThermal": 0, "productEpi": 0, "productFast": 0,
    "note": "Пример, требуется проверка сечений"
  }]
}
```

**Важно:** чтение серверного справочника не предоставляет браузеру прав на изменение файла. Для общего редактирования с сайта впоследствии потребуются серверное API, аутентификация и права доступа.
